# Plans

Use this folder for small, verifiable implementation plans.

Each plan should be narrow enough that the human can test it before moving to the next one.

Recommended format:

```markdown
# Plan #### — Title

## Goal

What this plan should accomplish.

## Scope

What is included.

## Out of Scope

What should not be touched.

## Implementation Notes

Guidance for the coding agent.

## Verification

Manual checks the human can perform.

## Completion Notes

Fill this in after the plan is completed.
```
