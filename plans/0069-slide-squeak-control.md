# 0069 — Slide Squeak Control

## Context

Human DAW listening accepted the EG-068 motion-coupled slide squeak as a large improvement over broadband noise, but the next musical need is balance. The slide squeak is useful, while the older note approach/release `Finger Noise` layer is still less convincing and should remain separate until it is revisited.

## Goal

Add an independent slide-grouped volume control for the finger/string noise generated by `Neck Slide` motion.

## Implementation

- Added a host-facing `Slide Squeak` parameter on the Performance page.
- Range is 0% to 200%, default 100%.
- 100% preserves the EG-068 balance for existing sessions and new instances.
- The control scales only the slide contact squeak/scrape layer inside `StringVoice`.
- `Finger Noise` remains the older note approach/release noise control.
- Added `GuitarAGOfflineRender --slide-squeak` for deterministic balance checks.
- Updated the model label to `StringVoice EG-069 SlideSqueakControl`.

## Verification Targets

- New plugin instances show `v0.2.6 / StringVoice EG-069 SlideSqueakControl`.
- The Performance page shows `Slide Squeak` with the other slide controls.
- `Slide Squeak` 0% mutes slide contact noise while preserving `Neck Slide` pitch, `Fret Steps`, and `Slide Lift` damping.
- `Slide Squeak` 100% matches the EG-068 balance.
- `Slide Squeak` above 100% can boost the slide contact layer without affecting the older `Finger Noise` approach/release layer.
