## Human Context

Human DAW audition and planning clarified two next needs:

- make the `Player Feel` slider easier to read as `Bot` at 0%, `Pro` at 50%, and a non-judgmental loose/sloppy range at 100%;
- start the Auto Strum interpreter so a DAW can author chord notes at the same timestamp and Guitar AG can perform the right-hand sweep internally instead of requiring staggered MIDI note starts.

## Implementation Summary

- Changed model label to `StringVoice EG-079 AutoStrum`.
- Added `Bot`, `Pro`, and `Loose` labels under the `Player Feel` slider.
- Added `Strum Speed` as a host/VST parameter and Articulation-page slider.
- Added offline-renderer `--strum-speed`.
- Added same-sample MIDI grouping in `AudioEngine::render`.
- Added exact-block Auto Strum behavior:
  - requires at least two note-ons at the same sample;
  - requires `Strum Speed > 0%`;
  - falls back to normal dispatch if same-sample controller/expression events are present;
  - predicts fretboard string assignments from the current `FretboardMapper`;
  - sorts the notes by `Pick Stroke` direction;
  - schedules per-string note-on delays internally;
  - preserves the predicted string assignment until the delayed note-on fires.
- Updated Player Feel processing so internally generated strum delays count as the effective picked-event time for load/recovery and deterministic timing variation.
- Added `scripts/create-auto-strum-audition-midi.py` and `tests/midi/guitar-ag-auto-strum-audition.mid`.
- Updated changelog, decisions, learnings, DSP notes, test plan, audition notes, build notes, plan 0079, review queue, project log, and session state.

## Known Limitations

- The Auto Strum interpreter only groups note-ons at the exact same sample. A near-time tolerance window is intentionally deferred because it implies collection latency/lookahead.
- Already-staggered MIDI strums are not rescheduled; they still use the EG-078 strum-aware Player Feel heuristic.
- Very short chord note lengths can still end before a slow generated strum completes; musical clips should leave enough held duration for the selected `Strum Speed`.
